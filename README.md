# CPEN 221 Practice

Practice problems in the style of CPEN 221 quiz Question 4: implement an abstract data type in Java with constructor validation (throwing `IllegalArgumentException`), a counting or filtering method, and a method that returns a collection.

Each folder holds the problem statement (`README.md`), the solution, and a test runner that checks every example from the problem.

## Running a problem

```
cd 01-dna
javac *.java
java DNATest
```

## Problems

| # | Problem | Practices |
|---|---|---|
| [01](01-dna) | DNA | junk filtering, `%` count check, `substring` chunks into a `Set` |
| [02](02-intervals) | Intervals | validating parallel arrays, building an `int[]` with a position counter |
| [03](03-readings) | Readings | skip vs throw with `continue`, count-then-fill arrays, reusing a method |
